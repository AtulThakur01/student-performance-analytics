# Student Performance Analytics System

A Python data-analysis project that reads student records from a CSV file, processes them with **NumPy** and **Pandas**, and prints a clear report: totals, averages, grades, pass/fail statistics, subject-wise performance, department-wise performance and top performers.

Built as the Python with AI project assignment for **EWB Courses**.

## Project Structure

```
student-performance-analytics/
├── main.py                  # Runs the project and prints the final analysis
├── functions.py             # Reusable calculation / processing functions
├── students.csv             # Dataset: 20 student records
├── student_results.csv      # Output generated by main.py (with grades and results)
├── sample_output.txt        # Saved console output of one full run
├── requirements.txt         # Python libraries needed
├── Project_Documentation.md # Full project documentation
└── README.md
```

## Technologies Used

- Python 3
- NumPy (numerical calculations: sum, mean, median, std, min, max)
- Pandas (DataFrame loading, filtering, sorting, groupby)

## Dataset

`students.csv` has 20 records with these columns:

| Column | Description |
|---|---|
| Student_ID | Unique ID (S001 to S020) |
| Name | Student name |
| Department | CSE, ECE, ME, CE or EE |
| Python, Mathematics, Physics, Electronics, English | Marks out of 100 |
| Attendance | Attendance percentage |

## Rules Used

**Pass / Fail:** a student passes only if they score at least **40 in every subject**. Otherwise the result is Fail.

**Grading (based on average marks):**

| Average | Grade |
|---|---|
| 90 and above | A+ |
| 80 to 89.99 | A |
| 70 to 79.99 | B+ |
| 60 to 69.99 | B |
| 50 to 59.99 | C |
| 40 to 49.99 | D |
| Below 40 | F |

A student who fails any subject is given grade **F**.

**Attendance:** below 75% is flagged as "Shortage".

## How to Run

1. Install Python 3 and the libraries:
   ```
   pip install -r requirements.txt
   ```
2. Run the project from the project folder:
   ```
   python main.py
   ```

## What the Program Shows

1. Dataset overview (records, columns, missing values)
2. Student-wise total, average, grade and result
3. Class summary (class average, highest and lowest scorer)
4. Pass / fail statistics
5. Grade distribution
6. Subject-wise analysis (average, highest, lowest, pass %)
7. Top 5 performers
8. Department-wise analysis
9. Attendance shortage alert
